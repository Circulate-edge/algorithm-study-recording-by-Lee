# 算法学习笔记与备赛题单

> 个人算法刷题与备赛资料库。按主题分文件记笔记，按周写周报，配一份面向新生比赛的题单。

## 一、这是什么

这个仓库不是项目代码库，是**学习过程的可回看记录**，包含三类内容：

- **算法笔记**（`NN主题.md`）：按知识点整理的模板代码、思路和对应题目；
- **周报**（`周报N.md`）：每周的刷题量、学到的东西、卡住的题，配套 PDF 在 `algorithmNote/`；
- **备赛题单**（`备赛题单.md`）：面向「猫鱼杯」新生赛的八阶段训练路线，全部题目来自洛谷。

目标只有一个：**下次遇到同类题，能从这里直接翻到可用的模板和踩过的坑。**

## 四、题单涉及的算法

题单分八个阶段，难度递增。下面按阶段说明每一步练的到底是什么、原理在哪。

### 阶段一 · 语法与基本模拟

**本质**：没有算法，只有「把中文规则一比一翻译成代码」的准确性。这一档丢分基本都丢在漏情况，不是不会写。

- **循环 + 计数**：固定次数遍历，边遍历边维护答案（陶陶摘苹果）。
- **打擂台求最值**：先把答案设成「不可能更差的值」，再逐个比较更新（不高兴的津津）。
- **逐位拆数字**：`n % 10` 取末位、`n /= 10` 去掉末位，循环到 0；统计某数字出现次数就靠这个（计数问题）。
- **取模构造循环**：把「第几天」映射到「星期几」，`(i - 1) % 7` 是关键（小鱼的航程）。
- **浮点输出**：`printf("%.3f")` 或 `fixed << setprecision(3)`，四舍五入规则要跟题目一致。

对应笔记：无专门笔记，散见 `周报1.md`。

### 阶段二 · 字符串与输出格式

**本质**：字符串题的难点不在算法，在**边界和格式**。一个多余空格就是 WA。

- **整行读入**：`getline(cin, s)` 会吃掉换行符，前面有 `cin >>` 时要先 `cin.ignore()`；或者干脆逐字符 `getchar()` 读到 `\n`。
- **单词边界**：判断一个单词出现，要保证它前后都不是字母，否则 `the` 会匹配到 `there`。
- **大小写统一**：`tolower` / `toupper` 逐字符转换后再比较，比手写条件判断可靠。
- **前导零**：数字反转类题要区分「小数部分」「分数部分」「百分数」，末尾的 0 该去、开头的 0 该留，必须分类讨论。
- **回文 + 日期合法性**：先判月、再判日，2 月要判闰年（`y%4==0 && y%100!=0 || y%400==0`）。
- **输出格式**：题目说「严格一致」时，先把期望输出抄到纸上，逐字符对，包括行末空格和换行。

对应笔记：`25字符串.md`（KMP，进阶内容，本题单不要求）。

### 阶段三 · 排序、STL 与前缀和

**本质**：这一阶段是**复杂度意识**的起点——用预处理把「每次查询都重算」变成「算一次、查 O(1)」。

- **`sort`**：$O(n\log n)$，比较函数必须满足严格弱序（只用 `<`，不要写 `<=`），否则会越界崩溃。多关键字排序就是比较函数里按优先级依次比。
- **前缀和**：令 $pre[i] = pre[i-1] + a[i]$，则区间和 $[l,r]$ 为 $pre[r] - pre[l-1]$。原理是「和」可减，所以能用两个前缀相减得到任意区间；单次查询从 $O(n)$ 降到 $O(1)$。
- **前缀和 + 取模**：$(pre[r]-pre[l-1]) \bmod 7 = 0$ 等价于两个前缀和模 7 同余，于是把问题变成「找同余的最远两端」（Subsequences Summing to Sevens）。
- **二维前缀和**：$pre[i][j]$ 表示左上角矩形和，查询用**容斥**：加两块、减一块重叠。最大加权矩形就是枚举上下边界压成一维再做前缀和。
- **差分**：前缀和的逆运算。令 $d[i] = a[i] - a[i-1]$，则区间 $[l,r]$ 整体加 $v$ 变成 `d[l] += v; d[r+1] -= v` 两次单点修改，最后求一遍前缀和还原。适合「多次区间修改、最后统一查询」（语文成绩）。
- **`set` / `map`**：底层红黑树，插入/查询 $O(\log n)$，自动去重（明明的随机数）、计数（A-B 数对）。
- **逆序对**：冒泡排序的交换次数 = 逆序对数；归并排序在合并时统计「右边元素比左边小」的次数，$O(n\log n)$（车厢重组）。
- **滑动窗口**：右指针扩张、左指针收缩，窗口内的信息增量维护（如各类计数），避免每次重扫窗口。要求「扩张/收缩后信息能 $O(1)$ 更新」。

对应笔记：`14前缀和.md`、`15差分数组.md`、`16滑动窗口.md`、`17双指针.md`、`03归并分治.md`。

### 阶段四 · 二分与贪心

**本质**：二分答案把「求最优值」变成「判可行性」，是本次比赛出现频率最高的技巧。

- **二分查找**：前提是**单调有序**。每次比较中点、砍掉一半，$O(\log n)$。`lower_bound` 找第一个 $\ge x$ 的位置，`upper_bound` 找第一个 $> x$ 的位置。
- **二分答案**：当答案 $x$ 满足「$x$ 可行 $\Rightarrow$ 所有比 $x$ 更宽松的值也可行」时，答案具有单调性，就可以在**答案值域**上二分，每次用 `check(mid)` 判可行性。看到「最大值最小」「最小值最大」「最多能装多少」，条件反射想二分答案。
- **`check` 函数才是主体**：二分只是外壳，真正的算法在判定里（跳石头 = 贪心删石头；刺杀大使 = BFS 判连通）。
- **边界处理**：整数二分用 `while (l <= r)` 或 `while (l < r)` 两种模板，注意 `mid = (l+r)/2` 与 `(l+r+1)/2` 的配对，配错会死循环；实数二分直接固定迭代 100 次，比判 `eps` 稳。
- **排序贪心**：按某个关键字排序后依次处理（排队接水按用时升序）。
- **区间调度**：按**右端点**升序排序，能选就选，这是「最多不重叠区间」的最优策略（线段覆盖）。
- **优先队列贪心**：每次取当前最小/最大的两个合并，堆维护，$O(n\log n)$（合并果子本质是哈夫曼树）。
- **对撞双指针贪心**：排序后一左一右，能配对就配，否则移动大的一端（纪念品分组）。
- 贪心的正确性靠**交换论证**：假设最优解不按贪心选，交换后不会变差。

对应笔记：`13二分.md`、`08贪心.md`。

### 阶段五 · 递归、DFS 与 BFS

**本质**：搜索 = 枚举所有可能，靠「标记已访问」把指数级降到能跑。

- **递归三要素**：终止条件（什么时候停）、本层做什么、怎么把结果传回去。递归深度受调用栈限制，深了会爆栈。
- **DFS（深度优先）**：一条路走到底，走不动再回退。连通块问题（Lake Counting、求细胞数量）就是「遇到未访问的点，DFS 把整个连通块标记掉，计数 +1」。
- **洪水填充**：DFS/BFS 的一种特例，把相邻且同类的格子染成同一标记，$O(nm)$。
- **回溯**：选择 → 递归 → **撤销选择**，本质是枚举所有方案（子集、全排列、八皇后）。剪枝（列/对角线已被占）是能不能过的关键。
- **BFS（广度优先）**：用队列按层扩展，**第一次到达某点时的步数就是最短步数**——前提是边权都为 1。这是 BFS 和 DFS 最本质的区别。
- **多源 BFS**：把所有起点一次性入队，等价于加一个虚拟超级源点，求的是「到最近起点的距离」（血色先锋队）。
- **BFS + 记忆化**：01 迷宫里同一个点在不同查询下答案可能不同，按连通块预处理一次、多次查询 $O(1)$。
- **二叉树遍历**：先序 = 根左右，中序 = 左根右，后序 = 左右根。已知「中序 + 先序/后序」可唯一还原树（中序负责划分左右子树，另一个序负责找根）。

对应笔记：`09递归.md`、`21洪水填充.md`、`周报6_二叉树.md`。

### 阶段六 · 动态规划（背包为主）

**本质**：把「重复计算的子问题」存下来。能用 DP 的前提是**最优子结构**（大问题最优解由小问题最优解拼成）+ **无后效性**（只关心状态，不关心怎么来的）。

DP 四步：定状态 → 写转移 → 定边界 → 定遍历顺序（保证用到的状态已经算好）。

- **01 背包**：`f[j] = max(f[j], f[j-w] + v)`，**体积必须倒序枚举**。倒序是为了保证 `f[j-w]` 还是「上一件物品」的状态，正序会让同一件物品被重复使用。
- **完全背包**：转移式一样，**体积正序**枚举，允许同一物品无限次使用。这就是「疯狂的采药」要体会的差别。
- **滚动数组 / 一维化**：二维的 `f[i][j]` 只依赖 `f[i-1][...]`，所以可以把「前 i 件」这一维压掉，这就是一维写法的由来。
- **多限制**：物品同时有重量和体积，就给状态**加一维**，循环多套一层，倒序规则不变。
- **线性 DP**：按位置递推，转移来自前面若干个位置（过河卒、数字三角形）。数字三角形从下往上推比从上往下推少判边界。
- **「选与不选」**：每件物品决策只有两种，DP 本质是在做全局最优的决策序列（5 倍经验日）。

对应笔记：暂无独立笔记，见 `周报2.md`。

### 阶段七 · 并查集与基础数学

**本质**：并查集管「谁和谁是一伙的」，数学部分管「怎么不超时地算」。

- **并查集**：每个集合是一棵树，`find(x)` 一路找根，`union(a,b)` 把一棵树的根挂到另一棵上。
  - **路径压缩**：`find` 时把沿途节点直接挂到根上，树高接近 1；
  - **按秩/按大小合并**：矮树挂到高树下，避免退化成链；
  - 两者一起用，单次操作近似 $O(1)$（严格说是反阿克曼函数）。
  - 用途：判连通、判环、Kruskal、统计集合个数。
- **字符串元素**：题目给的是人名/字符串时，先用 `map<string,int>` 映射成编号，再套并查集模板——这是最常见的手写组合。
- **线性筛**：每个合数只被它的**最小质因子**筛掉一次，所以是 $O(n)$，不是埃氏筛的 $O(n\log\log n)$。
- **质因数分解**：从 2 试除到 $\sqrt{n}$，除完剩下的 $>1$ 的部分本身是质数。
- **因数枚举**：枚举到 $\sqrt{n}$，成对加入，$O(\sqrt n)$。
- **快速幂**：把指数二进制拆分，$a^{13} = a^8 \cdot a^4 \cdot a^1$，每步平方，$O(\log n)$，配合取模防溢出。
- **`gcd`**：辗转相除 `gcd(a,b) = gcd(b, a%b)`，$O(\log n)$。

对应笔记：`20并查集.md`、`10数论.md`。

### 阶段八 · 综合提速与交互题

**本质**：从「会写」到「选得对、写得快」。

- **看数据范围反推算法**：$n \le 20$ 想暴搜/状压，$n \le 10^3$ 允许 $O(n^2)$，$n \le 10^5$ 只能 $O(n\log n)$，$n \le 10^6$ 要 $O(n)$。1 秒大约 $10^7 \sim 10^8$ 次常数操作。
- **读题速度**：Codeforces Div.3 全套 + Div.2 A~C，练的是「快速提取条件和约束」。
- **交互题三件事**：
  1. 每次输出后**必须刷新缓冲区**（`std::endl` 或 `fflush(stdout)`），否则双方互等直到超时；
  2. 读交互库回应要用匹配的读入方式（`cin >>` 还是 `getline`）；
  3. 询问次数有限，**先想清策略再开口**，别浪费在无意义的询问上。

## 六、踩坑提醒

这些都是真踩过的，考前扫一眼：

- **`long long`**：和、乘积、答案累加都先怀疑溢出。$10^5$ 个数相加就能超 `int`。
- **浮点输出**：保留几位就写几位，别用默认输出；浮点比较别用 `==`，用 `fabs(a-b) < 1e-9`。
- **输出格式**：大小写、空格、行末不能多空格、每组数据之间要不要空行。提交前把样例逐字符对一遍。
- **多组数据**：每组开始前把数组、标记、计数器清干净。
- **数组越界**：按题目上限**多开 5~10**，尤其是下标从 1 开始的前缀和/差分（`d[r+1]` 会用到 `n+1`）。
- **二分死循环**：`while (l < r)` 配 `mid = (l+r)/2` 时，更新必须是 `l = mid+1`，否则卡死。
- **BFS 入队即标记**：出队时才标记会导致同一点重复入队，内存爆掉。
- **递归深度**：链状数据递归 $10^5$ 层会爆栈，考虑改迭代或手写栈。
- **交互题不刷新缓冲**：直接 TLE，且报错信息看不出原因。
- **提交前手造极端数据**：$n=1$、全部元素相同、取值到上下界、答案恰好在边界。
